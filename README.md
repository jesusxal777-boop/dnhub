## Database (FREE) — Recommended: Supabase

**Use Supabase** (free forever tier):
- 500 MB database
- Auth included
- Storage for thumbnails/videos
- Realtime optional

### Steps to connect (2 minutes):

1. Go to [supabase.com](https://supabase.com) → Create free project
2. In SQL Editor run:

```sql
create table videos (
  id bigint generated by default as identity primary key,
  title text not null,
  category text,
  duration text,
  views text,
  thumb text,
  video_url text,
  created_at timestamptz default now()
);

-- Enable public read
alter table videos enable row level security;
create policy "Public read" on videos for select using (true);
```

3. Go to **Project Settings → API**
   - Copy **Project URL**
   - Copy **anon public** key

4. Open `js/app.js` and replace the sample array with the Supabase code that is already commented at the bottom of the file.

That’s it. The site will load videos from your free Supabase database.
